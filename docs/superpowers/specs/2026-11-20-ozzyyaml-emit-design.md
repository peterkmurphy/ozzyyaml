# ozzyyaml Emit — Design Spec

**Date:** 2026-11-20  
**Status:** Approved  
**Parent:** [2026-11-20-ozzyyaml-design.md](./2026-11-20-ozzyyaml-design.md)

## Intent

Add `ozzyyaml-emit`: dump `Value` trees to YAML 1.2.2 text. Value-level only
(not lossless). Correct Unicode anchors/aliases are a first-class requirement.

## Decisions

| Topic | Choice |
| --- | --- |
| Input | `Value` / `&[Value]` only — no event-stream emitter in v1 |
| Output | `String` first (`to_string` / `dump_all`); `io::Write` later |
| Shared nodes | Emit `&` / `*` by `Rc` identity; cycles via aliases |
| Style | **Flow default**; configurable **block** via options |
| Multi-doc | `dump_all` / `dump_all_with_options` with `---` between docs |
| Anchors | Names generated by emitter (ASCII `a`, `b`, … and Unicode when testing round-trip of composed Unicode-anchored graphs); per-document scope |

## Public API (crate `ozzyyaml-emit`)

```rust
pub enum EmitStyle {
    Flow,  // default
    Block,
}

pub struct EmitOptions {
    pub style: EmitStyle,
}

impl Default for EmitOptions { /* Flow */ }

pub fn to_string(value: &Value) -> Result<String>;
pub fn to_string_with_options(value: &Value, opts: &EmitOptions) -> Result<String>;

pub fn dump_all(docs: &[Value]) -> Result<String>;
pub fn dump_all_with_options(docs: &[Value], opts: &EmitOptions) -> Result<String>;
```

Errors: typed `Error` / `Result` (emit failures, e.g. internal invariant). No
panics on ordinary `Value` graphs including cycles.

## Emitter behavior

1. Walk the graph depth-first.
2. Maintain `HashMap<*const Value, String>` (or equivalent) of assigned anchor
   names for the current document.
3. On first visit of an `Rc` that will be referenced again (or always assign
   when `strong_count` / revisit detection says shared): emit anchor on the
   node, later visits emit alias only.
4. Practical algorithm: two-pass or “assign on second sighting” — either is
   fine if cycles and DAG sharing both work; prefer readable code.
5. Scalars: Core-compatible plain when safe; otherwise single- or
   double-quoted. Booleans/null/ints/floats use Core canonical plain forms
   (`true`/`false`, `~` or `null`, decimal / `0o`/`0x` as needed for round-trip
   through compose Core).
6. Collections: flow `[…]` / `{…}` when `EmitStyle::Flow`; block `- ` / `key:`
   when `Block`. Nested structures follow the selected style (v1: one global
   style, not per-node).
7. `dump_all`: for each document, reset the anchor map; separate documents with
   explicit `---` (first doc may omit leading `---` if a single doc would;
   multi-doc uses `---` before each doc after the first at minimum — match
   common YAML practice and document the chosen convention in the crate docs).

## Round-trip testing

- `compose → emit → compose` for scalars, collections, shared aliases, cycles,
  Unicode anchors (`&汉`), and multi-doc streams.
- Exact string equality of emit output is **not** required against original
  source (not lossless). Semantic equality of composed `Value` (with
  `Rc::ptr_eq` for aliases where applicable) is the oracle.

## Non-goals (v1)

- Event → text emitter
- Lossless style/comment/tag round-trip
- `io::Write` / streaming writer
- Serde, PyYAML-compat, Python
- Per-node mixed flow/block style
